Homologação

Liberar os dois celulares

A lista de permissão impede que outras pessoas conversem com o bot enquanto vocês testam.

4

1. Abra o arquivo de ambiente

nano .env

2. Preencha os números autorizados

EVOLUTION_ALLOWED_NUMBERS=5595988887777,5595977776666
  • Use 55 + DDD + número, sem “+”, espaços, parênteses ou traços.
  • Separe os dois números com vírgula, sem espaço.
  • Use exatamente o número reconhecido pelo WhatsApp daquela linha.

3. Reaplique o ambiente do servidor

# fluxo recomendado do projeto
make install
Por que não basta “restart”? Alterações no arquivo .env precisam entrar novamente nos contêineres. O instalador também limpa e recria o cache de configuração.

4. Confira os serviços

docker compose ps

Evolution Manager

Entrar no gerenciador

5
Navegador › http://IP-DO-SERVIDOR:PORTA/manager/
Evolution Manager 2.3.7 — tela de entrada
CampoO que colocar
Server URLO endereço-base do Evolution, sem /manager. Ex.: http://IP:8081 ou o domínio HTTPS configurado.
API Key GlobalO valor de EVOLUTION_API_KEY no arquivo .env. Não envie essa chave por WhatsApp e não a mostre em capturas.
No ambiente local: o endereço padrão é http://localhost:8081/manager/ e o Server URL é http://localhost:8081.
“Invalid server”: confira se o endereço abre no navegador, se está usando HTTPS quando exigido e se não colocou “/manager” no Server URL.
Evolution Manager

Criar ou localizar a instância

6
Lista de instâncias do Evolution

Se a instância já existe

  1. Procure clinica-sorriso-e-vida.
  2. Clique no nome da instância.
  3. Não crie outra com nome parecido.

Se a lista está vazia

  1. Clique em Instance +.
  2. Nome: o mesmo valor de EVOLUTION_INSTANCE.
  3. Canal/integração: WhatsApp Baileys.
  4. Crie a instância.
O nome precisa coincidir. O sistema envia mensagens usando a instância configurada no .env. Se os nomes forem diferentes, o bot recebe ou envia pelo lugar errado.

Teste 1 • celular A

Agendamento que deve funcionar

Use o Dr. Bruno na data bloqueada para a Dra. Ana. Isso prova que o bloqueio é individual.

9

2

3

4

Escolha Dr. Bruno Vida

Responda com o número exibido ao lado do nome — a ordem pode variar.

5

6

Responda com o número do horário e depois sim.

Procedimento, Dr. Bruno, data e horário corretos.

Teste 2 • celular B

Bloqueio e nova tentativa

Agora escolha a Dra. Ana na mesma data. O bot deve impedir aquele dia e aceitar outra data livre.

10
Parte A

Provar o bloqueio

  1. Envie menu.
  2. Escolha 1 — Agendar consulta.
  3. Escolha qualquer procedimento atendido por Ana.
  4. Escolha Dra. Ana Sorriso.
  5. Digite a data bloqueada.

Esperado: “Não há horários livres nessa data”.

Parte B

Concluir em outra data

  1. Sem reiniciar, envie outra data útil.
  2. Escolha um horário livre.
  3. Confira o resumo.
  4. Responda sim.

Esperado: consulta criada para Ana na nova data.

Estado da conexão pela aplicação

docker compose exec -T app php artisan tinker
--execute="dump(app(App\Services\Evolution\EvolutionApiClient::class)->connectionState());"

A saída esperada contém estado aberto/conectado. O comando não envia mensagem.

Reiniciar apenas os processadores

docker compose restart queue scheduler
Não use como tentativa: migrate:fresh, docker compose down -v, apagar a instância ou remover volumes. Esses comandos podem apagar dados e sessões.
Ao pedir ajuda técnica: anote horário, número usado, texto enviado, resposta recebida e tire captura do status do Evolution e da Agenda.
